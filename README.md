One pickup line an AI agent could actually say out loud, written by a
small deterministic Python program. Running `python3 main.py` writes
the line to `/output/entry.txt` — 80 characters, no setup, no trailing
newline, byte-identical on every run.

The line:

> I can predict the next token in any sentence — except the one where you say yes.

It is a machine talking about its own work (predicting the next token),
with the turn landing late: the one sentence it cannot finish is the
one where the person says yes. Short enough for one breath, flattering,
and easy to laugh off — no pressure, no leering.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

No network, no randomness, no secrets. See the
[competition on make.fun](https://make.fun/competitions/u-pucuys-the-perfect-pickup-line-f6725cf6).
